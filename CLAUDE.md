## Overview
**EatWithMe** is a 100% Local-First / Offline-First personal food discovery and map application for Ho Chi Minh City, Vietnam. It is a zero-framework, vanilla ES-module SPA served directly to the browser (no bundler for web, esbuild only for mobile bundling via Capacitor). All user data is persisted in `localStorage` with `IndexedDB` mirroring.

---

## Development Commands

### Running Locally
- **Start local server:** `npm start` or `npm run dev`
  - Runs zero-dependency Node.js static server at `http://localhost:4173` via `server.mjs`.

### Data Ingestion & Geocoding
- **Import & Geocode places from Excel:** `npm run geocode` (or `node scripts/import-excel-geocode.mjs`)
  - Parses `Eat with mi.xlsx` (`quán ăn` and `nước` sheets).
  - Uses multi-tier free geocoding engine (Photon OSM with Saigon proximity bias, Nominatim, ESRI ArcGIS, and landmark/district fallback).
  - Caches results in `data/geocoded-cache.json`.
  - Injects updated dataset directly into `const defaultPlaces = [...]` in `app.js`.

### Mobile & Build (Capacitor & esbuild)
- **Bundle web assets for mobile:** `npm run build:mobile` (bundles `app.js` with esbuild to `dist/`)
- **Sync Capacitor assets:** `npm run cap:sync`
- **Add native platforms:** `npm run cap:add:android` / `npm run cap:add:ios`
- **Open native IDEs:** `npm run cap:open:android` / `npm run cap:open:ios`

## Architecture & Code Structure

### Single-File Client (`app.js`)
The application logic resides primarily in `app.js` (~6,000 lines), organized into:
1. **Constants & Tokens:** Category colors/pins (`FOOD_CATEGORIES`, `PRICE_TIERS`, `ICONS`).
2. **`defaultPlaces`:** Inline JSON dataset generated by the Excel geocoder. Never hand-edit this array as it will be overwritten by `npm run geocode`.
3. **State Management:** Simple module-scope state objects (`state`, `mapState`).
4. **Rendering & Event Dispatching:**
   - Single-direction full app re-renders via `renderApp()`.
   - Delegated action dispatcher `handleAction(event)` switching on `data-action`.
5. **Map & Geolocation:**
   - Leaflet 1.9.4 with CartoDB Voyager tiles (`voyager_nolabels` and `voyager_only_labels`).
   - Hybrid geolocation engine with Capacitor Geolocation, browser GPS, and IP fallback.
   - Dynamic Haversine distance calculations.

### Cache-Busting Protocol (Important)
Whenever modifying `app.js` or `styles.css`:
1. Bump the query parameter `?v=NN` in `index.html` on both script and link tags.
2. Bump `CACHE_NAME = "eatwithme-shell-vNN"` in `sw.js` to match.

### Conventions & Style
- **Vietnamese UI Only:** All labels, placeholders, toasts, and descriptions are in Vietnamese.
- **No Emojis in UI:** Use clean Unicode typography symbols or SVG icons.
- **HTML Escaping:** Wrap all dynamic template string interpolations in `escapeHtml()`.
- **Styling Tokens:** Defined in `styles.css` (`--canvas`, `--paper`, `--ink`, `--coral`, `--herb`, `--gold`, etc.).
